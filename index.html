    Frequently asked questions

    What is Zoho MCP?

    Zoho MCP is a product built on the Model Context Protocol, a standard interface that lets AI agents work with business software. You create MCP servers that expose tools, actions and context from Zoho apps. MCP is the protocol; Zoho MCP provides the infrastructure, configuration UI, security and integrations.

    How is it different from chatbot builders or automation tools?

    It is the execution layer. Chatbot builders focus on conversation flow and automation tools run predefined rules. Zoho MCP exposes your apps’ data and actions so agents can coordinate multi-step work without rigid scripts.

    Are AI agents and Zoho MCP the same thing?

    No. The agent, powered by an LLM, interprets intent. MCP supplies the interface: which actions exist, how they work and what is allowed. It doesn’t make agents smarter, it makes them more capable of acting.

    Do I need coding experience?

    No. You can configure MCP servers, define tools and manage authentication through the UI with minimal code.

    Which models are supported?

    Zoho MCP is model-agnostic. GPT, Claude, fine-tuned or open-source models all work, as long as the agent speaks MCP through an MCP client.

    Is it secure?

    Access follows Zoho’s security protocols: access controls, encrypted data handling and audit trails. Agents run with user-level permissions, and Zoho supports OAuth for identity management.

    Which apps does it work with?

    Many Zoho apps, including CRM, Mail, Calendar, Desk, Cliq, Projects and WorkDrive, plus 500+ third-party apps such as Asana, Twilio, OneDrive and Notion.
